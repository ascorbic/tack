Press <kbd>?</kbd> on any board for this list, searchable. It's generated from the same list the board's key handling uses, so it's always the full set.

Shortcuts don't fire while you're typing in a sticky, a title or a field.

## Tools

Single keys pick a tool. <kbd>Esc</kbd> goes back to Select. People with view access only have Select, Hand and Comment.
